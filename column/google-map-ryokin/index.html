Googleマップに料金を載せる方法と、載せたほうがいい理由

Googleマップでお店を探す人は、たいてい2〜3店を見比べています。そのときに料金が見つからないと「高いかもしれない」「聞くのが面倒」と思われて、次のお店に移られがちです。この記事では、Googleマップに料金を載せる手順と、何をどこまで載せればいいかをまとめます。

料金がないと、なぜ選ばれにくいのか

お店を探している人の多くは、スマホでGoogleマップを開き、近くのお店をいくつか見比べます。そのとき見ているのは、だいたい次の4つです。

  1. 口コミの評価と件数
  2. 写真（お店の中・雰囲気・仕上がり）
  3. 料金
  4. 予約や問い合わせのしやすさ

口コミや写真がよくても、料金だけが分からないと「問い合わせてみないと分からない店」になります。電話で値段を聞くのは、思っている以上にハードルが高いものです。だいたいの金額が分かるだけで、問い合わせる側の気持ちはずっと軽くなります。

Googleマップに料金を載せる場所は3つ

Googleマップのお店の情報は「Googleビジネスプロフィール」という無料の仕組みで管理します。料金を載せられる場所は、主に次の3つです。

場所向いているもの
サービス（メニュー）メニュー名・料金・説明を1つずつ登録できます。整体の「初回60分」、クリーニングの「エアコン1台」など
商品写真つきで並べられます。ジムの「体験レッスン」「月4回コース」など、見せたいものを3〜5個
投稿・写真料金表の画像を写真に入れておく方法。手軽ですが、文字が小さいと読まれません

業種によって表示される項目は少し違います。まずは「サービス」から始めるのがおすすめです。

手順（スマホでもできます）

  1. お店のオーナーとしてログインしたGoogleアカウントで、Googleマップかブラウザで自分のお店の名前を検索します
  2. お店の管理画面（「プロフィールを編集」など）が出たら、「サービス」または「商品」を選びます
  3. メニュー名、料金、ひとことの説明を入れて保存します
  4. 反映まで少し時間がかかることがあります。数日たったら、ログインしていないスマホで表示を確かめましょう
オーナー登録がまだのお店はGoogleマップにお店が載っていても、オーナーとして確認（登録）していないと編集できません。登録は無料です。ハガキや電話、動画などで本人確認をします。

何を、どこまで載せればいい？

全部のメニューを載せる必要はありません。初めての人が一番気にする2〜3個だけで十分です。

業種まず載せたいもの（例）
整体院・整骨院初回の料金（検査込みか）、2回目以降の料金、保険と自費の違い
リフォームよくある工事の目安（例：トイレ交換 ○万円〜、クロス張替え 1㎡○円〜）。「〜」で幅を持たせてOK
ハウスクリーニングエアコン1台、お掃除機能付き、2台目以降、出張費の有無
パーソナルジム体験の料金、月4回コースの月額、入会金の有無

「現地を見ないと決まらない」業種でも、「○万円〜」と下限だけ載せるのがおすすめです。高すぎる誤解を防げますし、「この予算なら相談してみよう」と思ってもらえます。

あわせてやると効果が上がること

  • ホームページにも同じ料金を書く：Googleマップとホームページで金額が違うと、かえって不安にさせます
  • 予約ボタンをつける：料金を見て「行ってみよう」と思った人が、そのまま予約できると逃しません（ネット予約を無料で始める方法）
  • 口コミに返信する：返信のあるお店は、見ている人に「ていねいなお店」と伝わります

まとめ

料金を載せるのは、15分ほどでできる一番手軽な改善です。全部でなくていいので、初めての人が気にする2〜3個から始めてみてください。

自分でやる時間がない、どれを載せればいいか迷う、という場合は、のきさきの「Googleマップ整備（9,800円）」でまとめてお手伝いしています。

うちの場合はどうなる？
